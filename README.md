# 玛瑙 - AI 云端代码开发实验室

基于 K8S 的智能开发与实验平台，面向初学者、教师和竞赛团队。
技术栈：Vue3 + Spring Cloud Alibaba + K8S + AI。

## 目录结构

```
manao/  项目核心文件（PRD v4.0）
demo/   前端演示页（Node.js，端口 5777）
```

## 快速开始

```bash
cd demo
node server.js
```

浏览器打开 http://localhost:5777 即可查看演示页。
